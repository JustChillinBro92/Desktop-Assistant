# Desktop Assistant

A versatile desktop application built with Python, JavaScript, CSS, and HTML that provides helpful utilities and assistance features.

## Features

- User-friendly interface
- Cross-platform compatibility
- Responsive design with modern CSS
- Python backend for powerful processing
- JavaScript frontend for dynamic interactions

## Tech Stack

- **Python**: 54% - Core backend logic
- **JavaScript**: 25.4% - Interactive frontend
- **CSS**: 19.8% - Styling and layout
- **HTML**: 0.8% - Markup structure

## Installation

1. Clone the repository:
```bash
git clone https://github.com/JustChillinBro92/Desktop-Assistant.git
cd Desktop-Assistant
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
python main.py
```
